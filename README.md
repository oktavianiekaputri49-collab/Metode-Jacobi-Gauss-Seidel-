# Metode-Jacobi-Gauss-Seidel-
Dalam project ini dilakukan proses penyelesaian SPL dengan dua pendekatan, yaitu Jacobi dan Gauss-Seidel, untuk memperoleh solusi numerik melalui proses iterasi hingga mencapai nilai konvergen dengan error yang semakin kecil. Perhitungan dilakukan menggunakan Microsoft Excel untuk mempermudah analisis setiap perubahan nilai pada tiap iterasi.
